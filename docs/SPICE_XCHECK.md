## Top 5 suspected deviation sources

1. Inductor model uses fixed 50 mΩ series resistance in `sim.cpp`; RL rows can dominate.
2. LED/diode piecewise-linear fixed Vf (~0.7 V) differs from ngspice exponential junctions.
3. Capacitor backward-Euler stepping at 1 ms alters RC transient/steady-state observations.
4. BJT uses simplified beta/gm and saturation rather than a full SPICE Ebers–Moll model.
5. MOSFET/regulator models use fixed Ron, threshold and dropout values unlike vendor SPICE models.
