从面包板到 PCB 的一体化设计工具，手机上也能用。

在虚拟面包板上搭出电路，画出原理图，排布 PCB，然后实时仿真看它跑起来。桌面和手机都能用，完全离线，一个设计就是一个可分享的文件。

打开网页编辑器 查看分支发行版 完整文档（英文）

三个视图，一套连接

面包板

把元件拖到板上，引脚自动插入孔中。从任意孔或引脚拖拽就能拉出导线，用过的孔会变绿。

原理图

面包板上建立的连接会以飞线出现在这里。点一下飞线就变成导线，也可以直接引脚对引脚地画。

PCB

摆放封装、设置板框尺寸，用双层 A* 自动布线，或者自己点飞线。导出前先跑一次设计规则检查。

真的会跑起来

还能写程序

Arduino / ESP32

内置一个 Arduino C++ 子集解释器：逐行解释执行草图，delay、PWM、串口、OLED 绘图都能仿真，仿真时能看到执行到哪一行。

烧到真板子

桌面版通过 arduino-cli 编译并上传到真实开发板，串口监视器同样可用。

AI 助手

接上本机的 Claude Code、Codex 或 Gemini CLI，用一句话描述电路，它通过 MCP 在你的设计里加元件、连线、写程序。

版本历史与分享

  • 每次保存都会在本地留一个版本，可以随时回看和恢复。
  • 可同步到 GitHub 的私有仓库，换台设备也能接着改。
  • 可以把整个设计打包进一个链接，或者用 <iframe> 嵌进博客——读者能切视图、缩放、跑仿真，什么都无需上传。

快速开始

先查看本分支的 Releases 是否已发布对应平台的压缩包；未发布时请自行编译。网页版本需等待 Pages 工作流构建部署成功，可从 编辑器 或 嵌入预览 进入。部署操作指南说明首次启用步骤。

Windows   designElectronics-Windows-x64.zip   → 解压，运行 designElectronics.exe
macOS     designElectronics-macOS.zip         → 打开 designElectronics.app
Linux     designElectronics-Linux-x86_64.tar.gz
网页版    部署成功后打开本站 app/（项目路径为 /designElectronics/app/）

自己编译只需要 CMake 3.20+ 和一个 C++17 编译器，依赖只有 SDL3 与 SDL3_ttf：

git clone https://github.com/LeonhardtHUST/designElectronics
cd designElectronics
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j

界面语言

应用内置中英文界面，可在 视图 ▸ 语言 中切换，选择会被记住。翻译以 JSON 语言包形式编译进二进制；把改好的 i18n/zh-CN.json 放到程序旁的 i18n/ 目录即可覆盖，无需重新编译。 想补翻译或加新语言：运行 designElectronics --export-i18n ./i18n 导出完整模板， 改完用 python3 tools/i18n_check.py --strict 自检。
